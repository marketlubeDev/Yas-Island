Yas Island — Source Installation (Main Guide)

Version: 1.0 • Last updated:

This guide runs the app from source using Node.js. It covers local development and a simple production preview without mentioning any prebuilt artifacts.

Prerequisites

  • Node.js 18 or 20 (LTS) and npm

1) Use the downloaded files

Unzip the provided archive to a folder on your machine, then open a terminal in that folder.

2) Install dependencies

# from the project root
npm ci

# if npm ci fails (older npm), use:
npm install

3) Configure environment

Create a file named .env in the project root with:

# API base URL used by axios (config/axiosInstance.js)
VITE_BASE_URL=https://api.example.com

4) Run The App

Starts Vite dev server and SCSS watcher. Open http://localhost:5173. 

npm run dev

5) Deploying

  • Deploy using your hosting platform's standard SPA/Vite setup.
  • Because this is an SPA, configure your host to rewrite unknown routes to index.html so client-side routing works.
  • Share your final domain with the backend team to allowlist it for API/payment access.

Troubleshooting

  • If API calls fail, verify VITE_BASE_URL and CORS allowlisting for your domain.
  • If port 5173 is busy, stop the other app or change the dev server port via Vite config/CLI.
If you need help, share: where it's hosted, the URL you are testing, and a screenshot of any error.
