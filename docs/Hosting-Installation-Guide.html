Yas Island — Dist Installation (Simple Guide)

Version: 1.0 • Last updated:

This is a static website. You only need to serve the dist/ folder as-is. No build, no database, no server code.

What you received

  • dist/ — final production files
  • dist/index.html — main entry file (must be accessible)
  • dist/assets/ — JS, CSS, fonts, images

Local test (exactly on port 5173)

For local testing, the backend only allows requests from http://localhost:5173. Use this command to serve the dist folder on that port: 

npx serve -s dist -l 5173
# then open in your browser:
http://localhost:5173

Node.js requirement (only for local test)

The above command requires Node.js. Recommended version: Node.js 18+ (LTS). Hosting providers do not need Node.js if they only serve the static files.

Step-by-step (checklist)

  1. Install Node.js 18 or 20 (LTS). 
    # macOS (Homebrew)
brew install node

# Windows/macOS/Linux (installer)
# Download the LTS version from: https://nodejs.org
  2. Verify installation: 
    node -v
npm -v
    Expected: node shows v18.x or newer.
  3. Open a terminal in the folder that contains the dist directory, then run: 
    npx serve -s dist -l 5173
    If prompted: 
    Need to install the following packages:
serve@14.2.5
Ok to proceed? (y) y
    Type y and press Enter. This installs the package temporarily for this command; no global install needed.
  4. Open the site: 
    http://localhost:5173
  5. Stop the server when finished: 
    Press Ctrl + C in the terminal
  6. If port 5173 is busy, close the other app using it or change the port (e.g., -l 5174) just for testing. For backend allowlist, use 5173.

Upload to any hosting

  • Upload the contents of dist/ to your web root (so index.html is directly reachable).
  • This is a Single Page Application (SPA). If your host asks for a 404/Not-Found page, choose index.html.
  • No special server features are required. Just serve files as static content.

Important: Allowed origins

  • Local/UAT: Use http://localhost:5173 exactly (whitelisted).
  • Production: Share the final domain with the backend team to allowlist it for API/payment access.

Quick checklist

  • index.html loads in the browser.
  • Navigation works (no 404 on internal links). If it does, set your host's 404 page to index.html.
  • API/Payments work. If blocked, it is an allowlist issue — contact backend to add your domain.
If you need help, share: where it's hosted, the URL you are testing, and a screenshot of any error.
